Importa un articolo da Word

Carica il file .docx: il testo viene convertito nel formato del blog (titoli, grassetto, corsivo e note a piè di pagina incluse).

Scegli il file Word oppure trascinalo qui La conversione avviene tutta nel tuo browser: il file non viene caricato da nessuna parte.
  1. Converti il file con il tasto qui sopra.
  2. Copia il risultato.
  3. Nel pannello di amministrazione, apri (o crea) l'articolo e incolla il testo nel campo «Testo dell'articolo».
  4. Le note di Word diventano automaticamente note a piè di pagina numerate. Le immagini vanno caricate a parte (Cloudinary), come sempre.
